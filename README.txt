Quizmaster v9.0 — Modular Initial Version

v8.9 is the frozen visual/functional baseline.
v9.0 reorganizes the code into reusable JavaScript modules without intentionally changing the quiz behavior or layout.

Key modules:
- js/app.js — application state/actions and event routing
- js/components/ — reusable UI components
- js/questions/ — question-type renderers
- js/state/ — game state
- js/data/ — quiz loading/validation
- js/utils/ — shared helpers

JSON Edition has been removed from the visible title.
